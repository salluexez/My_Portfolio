# Mohd Salauddin Portfolio

A Flutter web portfolio inspired by aryansawhney.com, built around Mohd
Salauddin's resume, projects, skills, education, and contact links.

## Run Locally

```sh
flutter pub get
flutter run -d web-server --web-port 8080
```

## Build

```sh
flutter build web
```

Portfolio content and TODO links live in `lib/portfolio_data.dart`.
